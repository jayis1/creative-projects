# Examples

## Config-driven workloads

```bash
suffix-automaton run-config examples/report-config.json
suffix-automaton run-config examples/report-config.toml
```

## Output ideas

- export a rich JSON analysis report for dashboards
- generate repeated-substring summaries for corpus exploration
- compare multiple strings with pairwise longest-common-substring output
- inspect minimal unique substrings for genomic or log signatures
