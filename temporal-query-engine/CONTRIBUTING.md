# Contributing

Contributions are welcome. Please keep the interval model dependency-free and preserve half-open interval semantics.

1. Create a focused change with tests in `tests/`.
2. Run `python3 -m unittest discover -s tests -t .` and `python3 -m pytest -q` when pytest is available.
3. Run the CLI help and at least one example from the README.
4. Keep commits authored by jayis1 when working in the project automation pipeline.

Please explain any changes to Allen relation semantics or file formats in the pull request description.
